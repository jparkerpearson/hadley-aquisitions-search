Hadley AI's website positioning is "Hadley AI — the future of deal sourcing." The user defines three offerings: a full-on buy-side broker product; technology with email, voicemail, LinkedIn, Facebook, mail, and handwritten-letter capabilities; and market mapping with target and expert sourcing.

**Why:** The user explicitly requested this positioning and these offerings instead of the previous computational-reasoning messaging.

**How to apply:** Keep future website copy aligned with these three offerings unless the user changes the business direction. The user selected 48northpartners.com as design inspiration and supplied a Hadley AI logo and flyer as brand/content sources.

Use 48 North for its vibe, loading animations, and varied cards—not as a requirement to match its colors. The user values that it "feels great and not AI generated at all."

**Why:** The user explicitly clarified the design reference after the first plan interpreted it as a color direction.

**How to apply:** Preserve Hadley's distinct color identity and prioritize deliberate layout variation and polished motion over a generic repeated-card template.

The user supplied blue and white-on-blue Hadley logos and a Hadley brand style guide as the branding authority, replacing the earlier black serif logo direction.

**Why:** The user explicitly said "Use these for branding" with the new assets.

**How to apply:** Follow the supplied guide for colors and typography and use the new logo variants. Do not revert to the earlier logo or infer colors from 48 North.

Keep this website's copy very minimal. The user said there was "way too much random text, eyebrows, etc etc" and asked to "simplify this way down."

**Why:** The user rejected the text-heavy first redesign, then reiterated "Way too much happening here. Simple like the screenshot."

**How to apply:** Avoid decorative eyebrow labels, repeated explanations, and extra marketing sections. The supplied simple reference uses a flat dark background, bold headline, one short paragraph, and one text contact link. Avoid hero circles and other ornamental geometry. Use direct service names and short descriptions rather than adding copy to fill space.
